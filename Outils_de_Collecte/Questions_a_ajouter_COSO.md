# Questions à ajouter au questionnaire baseline COSO

Le questionnaire COSO est un sous-ensemble de l'ENE. Ce document liste les
questions à **réactiver depuis l'ENE** (source = ENE : comparabilité nationale)
et celles à **ajouter** (source = IE : échelles validées absentes de toute
enquête-emploi mais exigées par la théorie du changement COSO).

Priorité : 🔴 indispensable · 🟠 majeur · 🟡 utile
Codes : nouveaux codes insérés dans les sections existantes A→M.

### Note d'arbitrage (durée)
Le questionnaire est déjà à 35-40 min. Pour absorber ces ajouts :
- **Alléger** la branche statut-d'emploi (D→H) très détaillée de l'ENE (listes de codes
  exhaustives en H7/H12) — surdimensionnée pour une évaluation d'impact ;
- **Réinvestir** ce temps dans E-bis (profit), J (cohésion), R (résilience/FIES).
- Les modules 🔴 sont non négociables (ce sont les outcomes primaires + le traçage) ;
  🟡 sont à arbitrer selon le temps restant.
